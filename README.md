# Next.js Demo

Small Next.js App Router project for Superlog demo and integration testing.

## What is included

- Home, about, dashboard, and dynamic item pages
- Server routes for health, orders, and dynamic users
- TypeScript, ESLint, and the default Next.js dev workflow

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Routes

- `GET /api/health`
- `GET /api/orders`
- `POST /api/orders`
- `GET /api/users/:id`
